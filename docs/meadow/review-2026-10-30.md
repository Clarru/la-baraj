# Meadow review and local acceptance

Tested runtime: `1764 f 0 c`, integrated with released boat/wake 49, arcade 43, chat 53 and main-only deployment policy 54. Terrain, roads, cabin positions and arcade hooks are preserved.

## Review fixes

The old frame guard returned early for every delta above 250 ms, so sustained rendering below 4 FPS could never downgrade. A regression using 34 consecutive 300 ms frames failed before the fix. The bounded observer now counts sustained slow active frames, warms up for 6 seconds, requires 3 seconds of slow cost, and resets on visibility return. Healthy cadence and isolated stalls do not downgrade. Its buffer is retained instead of allocated on React rerenders.

The old streaming layer submitted every instance slot even with zero plants. The reviewed layer hides empty meshes and limits draw count to the last occupied instance, retaining fixed slot offsets. The chunk state is retained lazily. Hidden meshes discard accumulated partial upload ranges; returning meshes request a full refresh so previously cleared GPU slots cannot reappear as ghost vegetation. Native Three attribute tests cover empty/sparse/full limits and hide/show upload semantics.

Solo windows sit at the 120 Hz limit, so those results do not isolate the additional GPU time. These are not a zero-cost claim, uncapped GPU benchmark or guarantee for weak hardware. The author's earlier M 2 Pro/uncappedChrome results are retained separately and are not directly comparable.

All 14 recorded timing windows had 600 frames and zero frames over 33 ms. Three earlier crowd windows had unmatched moving-avatar phases and are retained as exploratory; the tightly timed off/high/off sequence at scene≈15 seconds is the primary crowd comparison. ## Visual and compatibility observations

High and low density both rendered correctly. Captured road/cabin/shore views retain clear spaces; unit placement cases also cover dock and activity exclusions. Plants create no physics bodies or colliders, confirmed by matched counts. No runtime errors were recorded across the captured navigations.
