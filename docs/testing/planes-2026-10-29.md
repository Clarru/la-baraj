# Planes follow-up verification — 29 October 2026

## Defects reproduced and corrected

1. **Ready during reconnect:** the last unready player could ready while an already-ready opponent was away, leaving both players ready in setup after reconnect. Ready is now disabled/rejected during the absence. Resuming also repairs a previously stored both-ready setup and starts it normally. A failing regression was observed before the fix and passes afterward.
2. **Folded draft loss:** folding/reopening the sheet or opening Menu unmounted the editor and discarded custom placement. A seated editor now stays mounted and hidden, with its interval paused. Both browser paths preserve the exact edited layout and restore keyboard focus on reopening.
3. **Repeated target copy:** a repeated square is rejected as an invalid target rather than reported as a storage failure. It consumes no turn or revision.

4. **Keyboard Menu activation:** the paper capture handler prevented native Enter/Tab actions outside the sheet. It now blocks game listeners while retaining native UI activation and focus navigation.
