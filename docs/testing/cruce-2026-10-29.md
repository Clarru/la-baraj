# Cruce verification — 2026-10-29

## Scope

This record covers the finished Cruce extension at the one physical east picnic table beside Planes. It covers the six supported modes (duel, three-player standard, three-player talon, four-player individual, four-player classic teams, and four-player standard teams), the four target scores (6, 11, 15, and 21), Iber and optional cheating, four physical seats, Romanian player-facing copy, private-hand privacy, reconnection and pre-game table states.

The extension inherits the La Baraj world and HUD. The runtime source of truth is `apps/web/src/game-art.css` plus `apps/web/src/cruce.css`: Alegreya Sans body text, Bree Serif headings, cool paper surfaces, slate-green ink, and the generated felt/timber material treated as the card table's object surface. This is a precisely pinned local extension; it does not create a replacement visual world or a concept-roll seed.

## Behavior and asset checks

- `packages/shared/cruce.ts` is the pure rules source for the 24-card deck, all six modes, all-pass redeal, standard-table cut/accept paths, bidding, trump, suit/trump/Iber legality, marriages, scoring penalties, target completion, cheating audit and the 1.8-second trick hold.
- `apps/server/cruce-table.ts` serializes actions, persists before publish, deduplicates request IDs, validates stored decks, keeps hands/stock/captures/offence audit private, holds a disconnected seat for 30 seconds and aborts without inventing a winner when a player leaves, expires or times out.
- `apps/web/src/CruceStation.tsx` places one felt-topped table at `CRUCE_TABLE` beside the Planes clearing and four one-person benches. There is no virtual table creation, room browser or private code path.
- `apps/web/public/assets/cruce/` contains 24 individually generated 363×585 WebP card faces, an authored geometric back, `felt.webp`, and `table-surround.webp`. Prompt/reference provenance and per-suit contact sheets live in `docs/art-direction/cruce/`; original reference PNG bytes are not shipped.
- Player-facing Cruce board, accessibility labels and server recovery messages are Romanian. The fixture's `Stare UI` selector and `Test local` annotation are explicit QA chrome, not production UI.

## Evidence limits and known drift

The browser captures use an offline authoritative-table fixture. They do not prove an avatar can walk to the physical table in the running 3D world, that live WebSocket multiplayer is deployed, or that the compatible Worker has been rolled out. Server/protocol tests provide logic and integration evidence, not a production deployment claim. The live occupied tromf.ro table was not entered because it requires authentication; the tutorial and public create-table settings were inspected instead. Generated cards and the felt/timber materials are original project assets and are not claimed to be pixel-identical to tromf.ro.

The root `DESIGN.md` retains older Barlow language from the broader La Baraj history. The actual current runtime uses Alegreya Sans/Bree Serif, as confirmed in `game-art.css` and the captured board. That pre-existing global drift is intentionally reported, not canonized into this Cruce extension and not repaired here; neither `DESIGN.md` nor `.impeccable/design.json` was rewritten.
