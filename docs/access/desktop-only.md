# Desktop-only entry

Phones and tablets see a short computer-only message before name onboarding, the lazy-loaded 3D scene, or the multiplayer connection. The check uses mobile browser signals, including iPadOS Safari's desktop-style user agent plus touch points. It does not block a desktop merely because its window is narrow or its screen supports touch. Browser-reported device signals can be spoofed and are not an authentication or security boundary.

Automated checks cover common iPhone, Android phone/tablet and iPadOS identifiers, a mobile client hint, desktop Safari/Linux/Windows and touch-enabled Windows PCs. An isolated mobile preview was visually checked at 390×844 and 320×568, and a narrow desktop window was checked to reach the game. The localhost-only preview override is excluded from production builds.
