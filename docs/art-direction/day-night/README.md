# Day and night

The shared clock follows real civil time in Romania using the Europe/Bucharest time zone, including daylight-saving changes. The room snapshot sends server time to correct device clock differences; before connection or offline, the device clock is used. The clock and lighting both read the same corrected time. There is no stored world state or new polling. The lighting moods follow the same local clock; they are artistic presets rather than seasonally calculated sunrise and sunset. The sky, fog, horizon, water, sunlight and fill blend through authored midnight, dawn, morning, midday, afternoon, sunset and evening moods. Night is deliberately brighter than physically accurate so players can navigate.

The clock numeral atlas `apps/web/public/assets/ui/clock-numerals.webp` is a compact 540×70 transparent WebP derived from an ImageGen image. Built-in ImageGen prompt: “Create a transparent sprite sheet of ten hand-lettered numerals for a small in-game clock, matching the craftsmanship and cream painted lettering of the attached La Baraj wooden sign. Exactly ten separate glyphs, in a precise evenly spaced 5-column by 2-row grid: top row 0 1 2 3 4; bottom row 5 6 7 8 9. Each glyph centered in its equal-sized cell with substantial empty transparent space around it, no glyph crossing cell boundaries. Consistent cap height, stroke weight and baseline, clear distinct numerals that remain legible very small, warm ivory with restrained dark brown edge and subtle hand-painted texture. No sign, no frame, no extra marks, no labels, no shadows beyond each glyph. Genuine transparent background.” The existing La Baraj banner was the style reference; cells were trimmed and packed in a single atlas. Generated source: `exec-e0ea0562-d54a-4392-a933-90f49a51cbd7.png`.

Implementation follows Three.js documentation for [directional sunlight](https://threejs.org/manual/en/lights.html), [matching fog and background](https://threejs.org/manual/en/fog.html), and [linear color management](https://threejs.org/manual/en/color-management.html), and React Three Fiber's advice to [mutate render-loop properties instead of triggering React renders](https://r3f.docs.pmnd.rs/advanced/pitfalls). Lighting is sampled once per second and applied without adding lights or geometry; existing water reflections remain throttled to 20 Hz.

Local visual checks covered midnight, dawn, midday and sunset at the cabin and lake. A 49-walker and 50-cabin fixture on an M4 Pro at 1707×960 and DPR 1.5 measured 73.9 fps baseline and 75.1 fps with this change (600 frames, p95 18.6ms and 18.9ms respectively). These are local synthetic-render measurements, not network capacity guarantees; the sun direction differs so draw counts are not directly comparable.
