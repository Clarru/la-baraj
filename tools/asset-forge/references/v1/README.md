# Fixed style reference kit v1

The same three boards and fixed prompt prefix are used for every new object. They are curated from original retained Quaternius CC0 reference renders; unfinished authored prototypes are deliberately excluded. The images describe style, surfaces and contact contrast, not a target object's identity.

`manifest.json` pins their order, role and hashes. A deliberate art-direction change creates a new kit version; callers do not swap references per item. The variable job brief, dimensions and component needs follow the fixed prefix.

Reproduce the boards with `build-reference-kit.py --crate <original-render-directory> --lantern <original-render-directory>`. Retain the original license notice in the repository's two-prop reference directory. These boards are developer inputs, not game downloads.
