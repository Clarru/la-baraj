# Appearance settings

Mode: Operate. This is an optional extension of La Baraj's existing Menu.
The user delegated implementation and review, requires at least three real modeled
men's options for hair, hats, tops, bottoms and shoes, and one brunette woman in the
supplied outfit. Preserve the approved male and all game controls.

## Direction contract

THESIS: Let people inspect a real character and deliberately apply a coherent look.
The exported animated model leads; option labels remain quiet and unambiguous.

OWN-WORLD: Inherit the current ImageGen paper-and-timber dialog frame, warm cream,
forest ink, Bree Serif headings and Barlow controls. Selection uses forest fill.

STORY: Open Menu → Appearance, select the body and modeled pieces, turn the preview,
then Apply or Cancel. A failed preview/save retains the previously applied look.

FIRST VIEWPORT: A large real 3D preview sits left, grouped choices right, Apply at
bottom-right. Short screens scroll controls independently; portrait stacks the panes.
The preview renders on demand and zooms to a selected category.

FORM: Precisely scoped settings extension of the existing dialog; no new visual
identity or concept tournament. Native buttons preserve keyboard and touch behavior.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Verify source/current exported meshes separately from ImageGen reference sheets.
Browser acceptance requires desktop, phone portrait and phone landscape, loaded
fonts/textures, preview rotation, Apply/Cancel, failure recovery, same-owner restore,
remote agreement and mobile rendering cost. No standalone local server is allowed.
