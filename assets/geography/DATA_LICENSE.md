# Geographic data and preview

The shoreline and road datasets in this directory are derived from OpenStreetMap.

**© OpenStreetMap contributors.** Data is available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1.0/). See [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright).

The GeoJSON datasets are provided under the ODbL, including the applicable database share-alike conditions. Preserve the data attribution and license on redistribution. The planning preview is a rendered work from that geographic data; its source datasets are included alongside it.

`source-manifest.json` records acquisition URLs, source feature version, counts and output hashes. No real buildings, house footprints, addresses or business listings are included. The geographic dataset does not contain elevation.

These data terms do not grant a license over original game code or independently authored buildings. Those are separate works. If elevation data is added later, record its separate source/license and required notices here before shipping it.
