# Wardrobe asset credits

Original base characters and modular outfits: Quaternius, CC0. Existing
source manifests and licence notices are retained in assets/wardrobe-source.

Canvas shoes adapt the shoe mesh from **Rex, Sprite Fright — Blender Studio**.
Source: https://studio.blender.org/characters/rex/v1/
Licence: https://creativecommons.org/licenses/by/4.0/
Changes: canonical foot fit, new cotton laces, materials, cloth surface bakes
and a reduced game mesh. Source character, rig, scripts and animation are excluded.

Female pumps adapt the stiletto bootie last by **MRT / Margaret Toigo**, CC0,
from the MakeHuman community shoes01 collection. The OBJ and clothing headers
identify MRT and CC0. Changes: low-cut upper, shorter toe, fitted heel and
canonical foot binding.
Source: https://static.makehumancommunity.org/assets/assetpacks/shoes01.html

Generated clothing design references guide the reconstruction; they are not
screenshots of the game models. Exported model checks are recorded separately.
