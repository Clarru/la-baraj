# Lake Cinciș asset feasibility study

Environment meshes by Quaternius, from CC0 source copies of Stylized Nature MegaKit, Medieval Village MegaKit and Fantasy Props MegaKit. Character study assembled from CC0 copies of Universal Base Characters, Universal Animation Libraries and Modular Character Outfits, with Blender adaptations and fitted hair/beard. The copies' notices, sources and hashes are retained in the project.

Original creator: https://quaternius.com/

Map data © OpenStreetMap contributors, ODbL: https://www.openstreetmap.org/copyright

Barlow and Barlow Condensed: SIL Open Font License, self-hosted through Fontsource. Phosphor icons retain their package license. Three.js, React Three Fiber, Drei, Rapier and Ecctrl retain their respective notices.

This is a local asset experiment, not the completed game. See the project report for source-level provenance and test limits.

The Lake_Roof_Gable, Lake_Roof_Low and Lake_Roof_Offset models are original project geometry generated in Blender with scripts/build-cabin-roofs.py. Cabin assembly, fire circle, geographic terrain and activity props are authored for this project.

Current cabin models Lake_Cabin_Gable, Lake_Cabin_AFrame and Lake_Cabin_Sage replace the previous experimental shell/roof assemblies. They are original project geometry reconstructed in Blender from the generated cabin reference grid under docs/art-direction/. Original procedural timber grain is generated by scripts/build-reference-cabins.py; source geometry and image provenance are recorded by scripts/optimize-cabins.mjs.

Additional original designs Lake_Cabin_GableBlue, Lake_Cabin_AFrameCopper and Lake_Cabin_SagePergola follow docs/art-direction/cabin-variants-grid.png (built-in image_gen; prompt saved alongside). Blender source construction: scripts/build-cabin-variants.py, reusing the established cabin geometry helpers.

Cincis_Oak_1 is original procedural project geometry created with `scripts/build-cincis-oak-v2.mjs`; its foliage and bark textures were generated with built-in ImageGen, with sources and prompts in `docs/art-direction/trees/`. Its distant sprite is rendered from that model with `scripts/bake-cincis-oak-impostor.mjs`. The oak replaces one generic forest slot in this feature branch.
