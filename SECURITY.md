# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's private vulnerability reporting on the repository's Security tab, when it is enabled. Include the affected component, impact, reproduction steps, and any suggested mitigation. Do not include actual player credentials or personal data in a report.

Please do not publish exploit details or test destructive attacks against the live game. We will review reports as maintainer capacity allows and coordinate disclosure once a fix is available. We cannot promise a specific response or fix deadline.

## Scope

The current `main` branch and the production La Baraj frontend and multiplayer service are in scope. Third-party services and other users' accounts are outside the project maintainers' control.
